# Exercise reference

One table per main muscle group, at most 7 exercises each. For every exercise: main and
secondary muscles, dynamic or iso, level (1 beginner · 2 intermediate · 3 advanced),
equipment, whether it's already in the app, and the sources behind it.

Once a batch is approved, its details go into the app so Suggest and Create can pick the right
exercises, rotate variations and match the user's level.
